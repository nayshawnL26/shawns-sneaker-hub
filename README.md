
# Shawn's Sneaker Hub

## Project Description

Shawn's Sneaker Hub is a responsive sneaker shopping website built with React. The website allows visitors to explore a sneaker collection, search for sneakers, view individual product details, and access a customer login page.

The project demonstrates React components, props, children composition, state management, effects, dynamic routing, and responsive design.

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- React Router v7

## Installation and Setup

1. Clone or download the project repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install the project dependencies:

   npm install

5. Start the development server:

   npm run dev

6. Open the local URL displayed in the terminal.

## Website Routes

- `/` - Homepage
- `/login` - Customer login
- `/shop` - Sneaker collection and search
- `/sneakers/:id` - Individual sneaker details
- `*` - Custom 404 page
